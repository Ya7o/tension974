# Firecrawl smoke test expected report

The smoke test should report:

- Firecrawl API key detected: yes/no
- Request executed: yes/no
- URL tested
- Content mode tested
- Raw counter text found, if any
- Extracted integer count, if any
- Database observation inserted: yes/no
- Error message, if any

Do not mark real scraping as validated if no Firecrawl API key was available.
